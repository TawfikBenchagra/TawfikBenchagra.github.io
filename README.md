# Tawfik Benchagra - Portfolio

A modern, responsive portfolio built with Next.js, Framer Motion, and Tailwind CSS.

## Features

- **Next.js 14**: App Router, static site generation.
- **Tailwind CSS**: Utility-first CSS framework for rapid styling.
- **Framer Motion**: Smooth animations and transitions.
- **Lucide React**: Beautiful, consistent icons.
- **Fully Responsive**: Looks great on desktop, tablet, and mobile.
- **Dark Mode**: Supports system dark mode preferences.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This portfolio is automatically deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the `master` branch.
